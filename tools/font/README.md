# tools/font/ — 変換済みフォント

入手した TTF/OTF を [`tools/make_font.py`](../make_font.py) で
VLW に変換したもの。文字集合は `tools/charset_ja.txt`（4415 字）。

**元の TTF/OTF はリポジトリに同梱していない**（書体ごとに再配布の条件が
違うため）。作り直すときは配布元から入手すること。

| `.vlw` | 本体。M5GFX が読む形式 |
|---|---|
| `.h` | 上を C の配列にしたもの。`main/fonts/` に置いて使う |
| `_missing.txt` | そのフォントに入っていなかった文字の一覧 |

---

## 置いてあるもの

**使っている2本だけ。** 派生物の再配布はライセンスの制約を伴うので、
どこからも参照していないものは持たない方針にした。

| ファイル | 元 | 使い道 |
|---|---|---|
| `gothic_18` | IPAex ゴシック 18px | **内蔵フォント**（`main/fonts/gothic_18.h` の元） |
| `maruminya_18` | x12y12px MaruMinya 18px | `22_font` が `meta.font` で指す実演用 |

> **`gothic_*` に書体名が入っていないのは意図的。**
> IPAex の派生物だが、IPA フォントライセンス第3条1項(4) が
> 「派生プログラムに許諾プログラムと同一・またはそれを含む名称を
> 使ってはならない」と定めているため、書体名では呼べない。
> 出所は [`README.md` の謝辞](../../README.md#謝辞とライセンス)。

切り替え方は [`main/fonts/active_font.h`](../../main/fonts/active_font.h)。
**`main/fonts/` に置くのは使う1書体だけ。** 1書体で 6〜7MB あり、
以前 8書体を溜めて 49MB になっていた。

## 書体を選ぶときの実測メモ

以前いろいろ変換して実機で見比べた結果。**同じ 16px でも書体で別物になる。**

### 行の高さが違う

| 書体 | ascent | descent | 行の高さ |
|---|---|---|---|
| Shippori Mincho / M PLUS 2 / 源ノ角 | 19 | −5 | 24 |
| IPAex ゴ / IPAex 明 | 15 | −2 | 17 |
| MaruMonica | 14 | −2 | 16 |
| MaruMinya | 12 | 0 | 12 |

**行の高さが変わると1画面に入る行数が変わる。**
IPAex 系は Shippori より 7px 低いので、同じ箱に 1〜2 行多く入る。
書体を替えたら `textboxes` の寸法を実機で見直すこと。

### 明朝は小さい寸法に耐えない

**IPAex 明朝は 16〜24px で細い横画が丸ごと消える。**
ヒンティングがヘアラインを 0 へ丸めるためで、変換ツールの問題ではない
（PIL で直接描いても同じ）。詳細と実測は
[`tools/README.md`](../README.md#明朝はこの寸法では使えない)。

明朝が要るなら Shippori Mincho のほうが小さい寸法でも残る。
ただし横画は中間の灰色になるので、電子ペーパーではやはり薄い。
**本文はゴシックを勧める。**

同じ理由で、**細いゴシック（M PLUS 2 Light / 源ノ角 Light）も
16px ではかなり薄い**。階調が 16 段しかないので細い線はディザに埋もれる。

### ドット系は設計サイズの整数倍・1.5 倍で

MaruMinya は **12px 設計**。拡大率が割り切れないと、
太い画と細い画が混ざって不揃いになる。

| サイズ | 倍率 | 見え方 |
|---|---|---|
| 12px | 1.0 | くっきり（native） |
| **16px** | 1.33 | **線が痩せて不揃い** |
| **18px** | 1.5 | **整う。同梱しているのはこれ** |
| 24px | 2.0 | 整う |

MaruMonica は 12×16px 設計なので 16px は縦方向が native。
ただし**漢字の送りが 12px** で、かなの 16px と混ざると詰まって見える。

ドット系は**アンチエイリアスを切って**変換すること（`--no-antialias`）。
中間調が入ると輪郭がぼやける。

### 縦書き用字形を持たない書体がある

縦書きの句読点・括弧は U+FE19〜FE48 へ差し替えて描く。
**元の TTF にこれが無いと、句読点が横書きの向き・位置のまま出る。**

| TTF | 縦書き用字形 |
|---|---|
| IPAex ゴ / IPAex 明 | 25/25 |
| Shippori Mincho | 22/25 |
| M PLUS 2 Light | 10/25 |
| x12y12px MaruMinya | **0/25**（縦書きには使えない） |

`make_font.py` の検証に `縦書き用字形 : 25/25 収録` と出るので、
縦書きで使う書体はそこを見ること。

### 収録字数

`charset_ja.txt`（4415 字）に対して、IPAex ゴ / 明はほぼ全部入る。
M PLUS 2 は 3918 字といちばん少なく、旧字体・異体字の収録が薄い。
何が落ちたかは `_missing.txt` に出る。

## 作り直す

```bash
python tools/make_font.py <ゴシック>.ttf --size 20 \
    -o tools/font/gothic_20.vlw --header main/fonts/gothic_20.h \
    --symbol font_gothic_20
```

作った `.h` を `main/fonts/` へ置き、`active_font.h` の `#include` と
`AYAME_FONT_DATA` を差し替える。
使い方は [`tools/README.md`](../README.md#make_fontpy)。

**派生物の名前に元の書体名を入れないこと**（上の但し書きと同じ理由）。
