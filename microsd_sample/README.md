# microSD カードの中身（サンプル）

**このフォルダの中身が、そのまま microSD カードのルートになります。**

```
microsd_sample/          ←  このフォルダが
   ├── scenarios/            ↓
   └── system/          ←  SD カードのルート

SDカード (E:\ など)
   ├── scenarios/       ←  ここへコピーする
   └── system/
```

`microsd_sample` というフォルダごとコピーするのではなく、
**中身（`scenarios` と `system`）を SD のルート直下に置いてください。**

---

## 入れ方

### USB で転送する場合

1. 本体を USB でパソコンにつなぐ
2. メニュー下段の **USB ボタン**を押す（アイコンが「切」表示に変わる）
3. パソコンにドライブとして見えるので、`scenarios` と `system` をコピー
4. もう一度 **USB ボタン**を押して戻す
5. 一覧が自動で読み直され、シナリオが並ぶ

> **USB を有効にしている間、本体はカードを読めません。**
> シナリオ一覧が空になりますが故障ではありません。USB を切れば戻ります。

### カードリーダーで入れる場合

SD を抜いてパソコンに挿し、ルート直下へコピーしてください。

## 中身

| パス | 内容 |
|---|---|
| `scenarios/<ID>/scenario.json` | シナリオ本体。**ファイル名は固定** |
| `scenarios/<ID>/thumbnail.png` | 一覧に出る絵。56×56 で表示。無ければ枠だけ出る |
| `scenarios/<ID>/images/bg/*.png` | 背景画像 |
| `system/settings.json` | 本体設定。初回起動時に自動で作られる |

**フォルダ名がシナリオIDです。** ASCII の英数字と `_` のみ、32文字以内にしてください
（日本語のフォルダ名は使えません。画面に出す題名は `scenario.json` の
`meta.title` に日本語で書きます）。

## サンプル一覧

12 本入っています。**1ページに 8 件なので 2 ページに分かれます**
（上下スワイプで送れることの確認を兼ねています）。

| フォルダ | 一覧に出る名前 | 確かめられること |
|---|---|---|
| `01_momotaro` | 桃太郎（総合サンプル） | 分岐・変数・ルビ・音・入れ子の条件分岐 |
| `02_pagesend` | ページ送りの確認 | 長い本文が複数ページに分かれる |
| `03_ruby` | ルビの確認 | 半角/全角の記法、長い読みのはみ出し、横書きのルビ |
| `04_sound` | 音の確認 | 単音・音列・休符。**サウンドを切ると鳴らないこと** |
| `05_transition` | 画面遷移の確認 | 背景の切替と 10 種の遷移を順番に |
| `06_minimal` | 最小構成 | `text` ひとつと `end` だけ |
| `07_broken` | 壊れたシナリオ（警告の確認） | **わざと壊してある**。下記参照 |
| `08_unimplemented` | 未実装コマンドの確認 | `chara` / `save` / `load` が無視されること |
| `09`〜`11_filler` | 一覧の9〜11番目 | ページ送りの確認用 |
| `12_metalast` | （フォルダ名が出る） | 下記参照 |

### わざと問題を入れてあるもの

この2つは**正常に動かないのが正しい**サンプルです。

**`07_broken`** — 存在しないシーンへの `jump`、未定義の背景名、無い画像ファイルを含みます。
起動時のログに `SCENARIO` タグの警告が並び、**それでも起動は止まらない**のが期待動作です。

```
W (xxx) SCENARIO:   scene 'main': jump to undefined scene 'no_such_scene'
W (xxx) SCENARIO:   scene 'main': background 'undefined_name' is not in assets
W (xxx) SCENARIO: Validation found 3 issue(s). Loading anyway
```

**`12_metalast`** — `meta` をファイルの末尾に置いてあります。
一覧のタイトルは各 `scenario.json` の**先頭 4KB だけ**を読んで取り出しているため、
このシナリオは**題名ではなくフォルダ名が表示されます**。
これは仕様どおりの動作です（`SCENARIO_SPEC.md` の 3.1 を参照）。
サムネイルも置いていないので、枠だけが出ます。

## 自分のシナリオを作るには

1. `scenarios/` の下にフォルダを作る（ASCII の英数字と `_`）
2. `01_momotaro/scenario.json` をコピーして書き換える
3. `thumbnail.png` を 56×56 で置く（任意）

書式は [`../SCENARIO_SPEC.md`](../SCENARIO_SPEC.md) にまとまっています。
使えるコマンドの一覧と、まだ使えないものは 4 章の表を見てください。

> **`meta` はファイルの先頭付近に置いてください。** 後ろにあると
> 一覧にフォルダ名が出ます（`12_metalast` がその例です）。
